# Lumina - 北欧・ナチュラルモダンなWebメディア (HP)

北欧・ナチュラルモダンなデザインを取り入れたWebメディアのホームページ（HP）です。  
レイアウト構造やコンポーネントの共通化を図り、保守性の高いHTML/CSS設計およびJavaScriptによる動的な演出を実装しています。

👉 **[公開ページ（GitHub Pages）を見る](https://norihumi.github.io/lumina-webmedia-hp/)**

## 🛠 使用技術
- **HTML5**（セマンティックな構造化）
- **CSS3**（FLOCSS記法をベースにしたモジュール設計、レスポンシブ対応）
- **JavaScript (ES6+)**（DOM操作、イテレーション処理）

---

## ✨ 設計・実装のこだわり

### 1. 保守性と拡張性を意識したCSS設計
- **レイアウトとパーツの分離**
  - 外箱・内箱などの骨組みには `l-` プレフィックス（`l-section`, `l-inner`）を採用。
  - コンポーネントには `c-` プレフィックス（`c-card`, `c-title` 等）を付与し、ベース（共通化）と差分を明確に分離しました。
- **管理しやすいレスポンシブ戦略**
  - セクションごとにメディアクエリをまとめる運用を行い、コードの検索性と保守性を高めています。

### 2. JavaScriptによる動的演出
- **繰り返し処理の「型」を活用**
  - `querySelectorAll` で取得した複数の要素に対し、`forEach` を用いた一括制御を実施。
- **ユーザー体験を高めるインタラクション**
  - サイドメニュー開閉、スライダー、フェードインアニメーション、カテゴリフィルター等の動的機能を搭載。
